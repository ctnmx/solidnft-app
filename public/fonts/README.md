# Monument Grotesk

Monument Grotesk est une fonte commerciale (Dinamo — abcdinamo.com) : les
fichiers ne peuvent pas être versionnés ici.

Pour l'activer :

1. Déposez dans ce dossier `MonumentGrotesk-Regular.woff2` et
   `MonumentGrotesk-Medium.woff2`.
2. Décommentez les blocs `@font-face` en haut de `src/index.css`.

Sans ces fichiers, le site utilise la pile de repli déclarée dans
`src/index.css` (Neue Haas Grotesk / Helvetica Neue / Arial), visuellement
très proche.
